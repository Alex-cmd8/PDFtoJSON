# dane/test: стресс-тесты парсера PDF → JSON

Структура такая же, как в `dane/przyklad_XX`: в каждой папке `test_XX_*` лежат PDF и эталонный JSON
(`odwolanie.pdf → odwolanie.json`, `pelnomocnictwo.pdf → pelnomocnictwo.json`,
`potwierdzenie_przelewu.pdf → przelew.json`).

Тесты **не копируют** макеты из примеров. Все документы свёрстаны по-другому, и каждый кейс
бьёт в конкретное место, где парсер, подогнанный под примеры, скорее всего ошибётся.
Схема JSON и соглашения взяты строго из эталонов в `dane/przyklad_XX`, а именно:
- из консорциума в `Odwolujacy` попадает только лидер;
- в `pelnomocnik` записывается первый указанный пełnomocnik;
- BZP пишется без пробелов (`2026/BZP00512377`);
- номер TED переводится в формат `NNNNNN-RRRR`;
- IBAN пишется без `PL` и без пробелов;
- NIP/KRS/REGON записываются только цифрами;
- если даты или места в шапке нет, ставится `null`.

| Кейс | Что проверяет |
|---|---|
| 01 формы дат и идентификаторов | NIP `999-541-27-83` и `PL 999 330 72 18`, KRS с ведущими нулями, 14-значный REGON; даты прописью, через `/`, с римским месяцем; дата-ловушка в тексте; сумма `-17,00 PLN`; IBAN без PL; заголовок перевода без диакритики |
| 02 без пełnomocnika | Odwołujący действует сам. Есть **только** `odwolanie.pdf` |
| 03 три заказчика | Ведущий заказчик стоит в списке **вторым** → `prowadzacy_postepowanie` = `[0,1,0]`; заказчики перечислены раньше odwołującego; есть и BZP, и TED |
| 04 три пełnomocnika | Титулы `adw. dr hab.`, `r. pr. dr`, `apl. r. pr.`; двойные фамилии; два PESEL; сумма 51 zł |
| 05 консорциум из трёх | Лидер — физлицо (CEIDG, KRS = null); смешанные `typ`; разное число подписантов |
| 06 табличная вёрстка | Стороны и pełnomocnictwo оформлены таблицами; у перевода другие подписи полей (`Tytułem`, `Identyfikator transakcji`) |
| 07 ловушки в переводе | Четыре даты (zlecenia/operacji/księgowania/wygenerowania) и несколько сумм (prowizja, итог, saldo); получатель стоит раньше отправителя |
| 08 разрыв страниц | Название закупки разорвано между страницами и разбито переносами `wdro-/żeniem`; водяной знак «KOPIA»; колонтитул с датой |
| 09 скан | Все три PDF — картинки **без текстового слоя** (200 dpi, лёгкий поворот, шум) |
| 10 без даты, только TED | В шапке нет даты и места → `null`; TED в формате `Dz. Urz. UE S: 2026/S 087-123456` |
| 11 выписка из счёта | Три операции: взнос за обжалование 7 500 zł, opłata skarbowa 17 zł и поступление. Нужна opłata skarbowa; действие описано синонимами |
| 12 спецсимволы | Кавычки внутри названий («ŻUBR»), `&`, `–`, скобки; разрядка `O D W O Ł A N I E`; e-mail с `+` |

Подробности и **допущения** (места, где примеры не задают соглашение, например
`przez-pelnomocnika: 0`) лежат в `manifest.json`, в поле `zalozenia`.
Если в вашей команде принято другое соглашение, поправьте ожидаемый JSON.

## Как запустить

1. Прогоните парсер на каждом `test_XX_*` и сложите результаты в отдельную папку с той же структурой
   (`wyniki/test_XX_*/odwolanie.json` и т. д.).
2. `python dane/test/porownaj.py dane/test wyniki`: скрипт выводит расхождения по полям и итоговую долю совпадений.

## Перегенерация

`python dane/test/_generator/generate.py dane/test` (нужны `reportlab`, а для скана ещё `pdftoppm`, `Pillow`, `img2pdf`).
Генератор детерминирован: PDF и JSON строятся из одной спецификации, поэтому они всегда согласованы.
Все данные вымышленные (NIP/KRS с префиксом 999, домены `.example`).
